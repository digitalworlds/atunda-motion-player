Atunda Dance Project

Load, rename, or remove dance

Type a dance name if you want, then choose a .json dance file. It loads when you click Load dance. If that file is already loaded, changing the name and clicking Load dance only renames it. Remove dance drops the selected dance from the list until you refresh.

Load, rename, or remove character

Type a character name if you want, then choose a .glb file. It loads when you click Load avatar.
